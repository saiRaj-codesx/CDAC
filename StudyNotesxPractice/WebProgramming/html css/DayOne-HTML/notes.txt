HTML: Hyper Text Markup Language

HTML is used to create a skeleton/structure 
HTML is used to display data on a web page

.html -> file

html code -> tags only

with the help of tags we can display things on the web page
HTML has all the predefined tags
HTML is case insensitive 
<form> <FORM> <fOrM>
HTML is error free

Two types of tags:

1. Container tag: both opening and the closing <form> </form> <body> </body> 
2. Empty tag: only opening, these tags don't have any scope <br> <img>

<html>
    <head>
        <title>My first page</title>
    </head>
    <body>
        <p>hello world</p>
    </body>
</html>

p -> every p will always be started from a new line
span -> span can sit in a same line 

6 heading tags 
 
h1 h2 h3 h4 h5 h6

<h1>Heading 1</h1>
        <h2>Heading 2</h2>
        <h3>Heading 3</h3>

every tag is having their own set of attributes/properties using which we can customize the tag

<p align="left|right|center"></p>

image:

if image file and the web page are at the same level 
<img src="filename.png" width="" height=""> 1900 x 1080 -> 500 x 300
<img src="photo.png" width="500" height="300">

if image has been moved into another folder:
 <img src="images/photo.png" width="500" height="300">

../ is for coming out one level from the current folder
<img src="../images/photo.png" width="500" height="300">


how to display links:
anchor tag
<a href="https://www.flipkart.com">Visit flipkart</a>
