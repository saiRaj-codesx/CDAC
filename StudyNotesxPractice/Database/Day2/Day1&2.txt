	  File System Drawback
1. Data Redundancy : The same data may be stored in multiple files 
2. Data Inconsistency : If the data is updated in one file but not in other related files, different files may contain different values or inforamtion.
3. Difficulty in Data Access : 	  Retrieving required information may require writing a new program or script for particular data.
4. Data Isolation : Data is scattered across different files and formats , making it difficult to combine and access it.
5. Integrity Problem: 
6.Security Problem:  File system generally provides limited and less flexible control over who can access or modify the data.
7.Concurrent Access Problem: when multiple users access or update the same file simultaneously, data may become inconsistent or corrupted. 
8.Automicity Problem:

	Cross Join:
	
	it is a join that combines every row from the first table with every row of the second table 
	
	select s.name, d.dept_name
	from student as s 
	cross join department as d
	
	purpose: to produce every possible combination of rows from the two tables:
	condition : no conditon
	
	Inner Join: 
	returns only rows for which the join condition finds a match in both tables:
	
	select student.student_id, student.name , department.dept_name
	from student 
	inner join department 
	On student.dept_id=department.dept_id order by student.student_id;
	
	Equi Join:
	(=)
	
	an equi join is a join in which the matching condition uses the equality operator (=).
	
	select s.student_id,s.name, d.dept_name
	from student as s
	join department as d
	On s.dept_id=d.dept_id;
	
	
	Old syntax: using where clause 
	
	select s.student_id,  s.name, d.dept_name
	from student as s , department as d
	where s.dept_id=d.depart_id;
	
	
	Join with using 
	using is convenient when both the tables have a join column with exactly same name.
	
	select s.student_id, s.name, d.dept_name
	from student s 
	join department d
	Using (dept_id);
	
	
	Natural Join:
	Natural join automatically matches columns that have same name in both the tables;
	
	Select s.student_id, s.name, d.dept_name, d.dept_id
	from student as s
	natural join department as d;
	
	Non-equi join: 
	the join condition comapres a vlaue with range instead of matching two columns usign equality.
	
	select s.student_id, s.name, s.dept_id as my_dept_id , d.dept_id 
	from student as s
	join department as d
	On s.dept_id > d.dept_id;
	
	Left join:
	
	it returns every row from the left table with matching row from the right table:
	
	select s.student_id, s.name, d.dept_name
	from student s
	left join department d
	On s.dept_id=d.dept_id
	order by s.student_id;
	
	
	right join:
